# NetScope Project Plan

NetScope already scans eight local ports, displays results, and exports JSON.
The next goal is a reliable, tested portfolio version.

## Plan parts

Each part has its own checklist and completion check. Check items off in the
individual files as the work is completed.

1. [Strengthen localhost restrictions](01-localhost-restrictions.md)
2. [Make scan results accurate](02-scan-results.md)
3. [Add automated tests](03-automated-tests.md)
4. [Improve the dashboard](04-dashboard.md)
5. [Make installation reproducible](05-installation.md)
6. [Prepare the portfolio demonstration](06-portfolio-demonstration.md)

## Working order and scope

Work in this order, adding tests alongside each scanner change. Keep external
scanning, exploitation, and public deployment outside this version's scope.
